### 4. 🧬 De Novo Genome Assembly

**Notebook:** `De_Novo_Genome_Assembly.ipynb`

A computational workflow demonstrating the fundamental concepts involved in reconstructing genome sequences from sequencing data without relying on a reference genome.

**Workflow concepts:**

```text
Sequencing Reads
      ↓
Quality / Read Processing
      ↓
Overlap / Graph-based Assembly
      ↓
Contig Generation
      ↓
Genome Reconstruction
```

**Key concepts:**

* Genome assembly
* Sequencing reads
* Contigs
* Assembly algorithms
* Genomic data analysis
